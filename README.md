# 🥤 Sedia Botolku

**Sedia Botolku** adalah proyek website toko online fiktif yang menampilkan
berbagai **botol minuman** untuk kebutuhan sehari-hari, olahraga, sekolah,
kantor, hingga aktivitas outdoor. Proyek ini dibuat untuk melatih kemampuan
membangun aplikasi e-commerce, mulai dari tampilan katalog hingga alur
keranjang belanja.

> ⚠️ **Catatan Penting:** Repositori ini dibuat **hanya untuk keperluan
> portofolio dan pembelajaran**. Sedia Botolku bukan toko sungguhan, produk,
> harga, dan data kontak yang tampil hanya berupa contoh (dummy), dan tidak
> ada transaksi jual beli yang sebenarnya.

## 🎓 Tujuan Proyek

- Sebagai portofolio untuk menunjukkan kemampuan pengembangan web
- Media belajar membangun fitur e-commerce (katalog, keranjang, checkout)
- Latihan merancang struktur yang rapih dan efisien
- Latihan merancang UI/UX yang responsif dan rapi
- Latihan menggunakan Git dan GitHub dalam mengelola proyek

## 🛠️ Tech Stack

Berikut adalah teknologi yang digunakan dalam proyek ini:

- NextJS
- TailwindCSS
- TypeScript
- React Icons
